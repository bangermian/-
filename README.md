# 高考顺 gaokaoshun

> 把高考录取**位次**当作股票 **K 线**来分析：大盘、板块、个股三个维度，看一所学校、一个地区、一个层次的高校历年到底变难还是变容易。

位次（排名）不受试卷难度影响，跨年可比，所以它比分数更适合做趋势分析。
本项目用 ECharts 画出 K 线、成交量（招生人数）、分差（校内专业冷热差），并聚合出区域指数与板块指数。

## 快速开始

数据只在你的浏览器里解析，不会上传到任何服务器。

### 方式一：在线访问（最省事）

部署在 GitHub Pages 后直接打开项目主页，然后点右上角「📁 加载文件夹」选择本地数据目录。

### 方式二：本地一键启动（推荐，零依赖）

双击项目根目录的 **`启动.cmd`**。

它会调用 `tools/serve.ps1`（纯 PowerShell 写的静态服务器，不需要 Node / Python），
自动打开 <http://127.0.0.1:8137/>。

> 为什么不能直接双击 `index.html`？
> 本项目用 ES Module 组织代码，浏览器出于安全策略禁止在 `file://` 协议下加载模块。
> 直接打开时页面会显示明确提示，而不是白屏。

### 方式三：已有 Node.js

```bash
node tools/serve.mjs        # 默认 http://127.0.0.1:8137/
# 或
npm start
```

## 数据怎么准备

### 目录结构

按**学校所在地**分文件夹存放，系统会递归读取，可多次加载不同文件夹（自动合并）。

```
data/
├── 天津/
│   ├── 2024 天津 天津工业大学 doublefirst 70800.xlsx
│   └── 2025 天津 天津工业大学 doublefirst 74000.xlsx
└── 浙江/
    ├── 2024 天津 温州肯恩大学 s11 70800.xlsx
    └── 2025 天津 温州肯恩大学 s11 74000.csv
```

一级文件夹名 = 学校所在地，用于「地区板块」聚合。

### 文件名

```
年份 招生省份 院校名称 板块 考生数.xlsx
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 年份 | ✅ | 4 位数字 |
| 招生省份 | ✅ | 该校在哪个省招生 |
| 院校名称 | ✅ | 允许包含空格 |
| 板块 | ⬜ | `92` / `doublefirst` / `newresearch` / `s11` / `shuangfei`，缺省按双非 |
| 考生数 | ⬜ | 该省当年考生总数，用于把位次换算成百分位 |

### 表格内容

至少要有 `专业名称` 和 `最低位次`：

| 列 | 必填 | 缺省行为 |
| --- | --- | --- |
| 专业名称 | ✅ | 空行直接跳过 |
| 最低位次 | ✅ | — |
| 最高位次 | ⬜ | 用最低位次填充 |
| 最高分 / 最低分 | ⬜ | 缺一补一；都缺则不画分差图 |
| 录取人数 | ⬜ | 按 0 处理（聚合权重退化为等权） |

支持 `.xlsx` / `.xls` / `.csv`；CSV 自动识别 UTF-8 与 GB18030（Excel 导出的中文 CSV 常是后者）；
表头不在第一行也没关系，会向下扫描 12 行自动定位。

## 计算口径

```
专业平均位次 = (最高位次 + 最低位次) / 2
院校收盘位次 = Σ(专业平均位次 × 录取人数) / Σ(录取人数)
开盘位次     = 上一年收盘位次（首年 = 当年收盘）
上/下影线    = 当年所有专业里最好 / 最差的位次
百分位       = 加权平均位次 / 参与省份当年考生总数 × 100
热度指数     = 100 - 百分位
```

**分母怎么取**：每个桶都记录「实际参与统计的招生省份」，分母 = 这些省份当年考生数之和。
既不会把没有数据的省份算进来，也不会跨年串号。分数缺失考生数时用 70000 兜底，并在悬浮提示里标注「估算」。

**视觉约定**：个股纵轴翻转（第 1 名在最上方），指数纵轴正常；
两种模式都满足「向上 = 更难考」，红色统一表示「比上一年更难」。这与说明页的描述一致。

## 相比旧版的改动

旧版是一个 1368 行的单文件 `gaokaoshun.html`。这次重写修掉了下列问题：

| 类别 | 旧版 | 现在 |
| --- | --- | --- |
| 均线周期 | 读取 `ma1~ma4` 输入框，但 HTML 里根本没有这些元素 | 侧栏有真实的四个输入框，改动即时重绘并记住设置 |
| 大盘/板块手动录入 | 表单完整，但 `addData()` 直接弹「暂不支持」 | 移除这些无效表单（指数是聚合结果），改为在「个股」页录入 |
| 指数分母 | 只取**第一个文件**的考生数当全局分母 | 按「省份 × 年份」分别记录；分母 = 参与省份之和 |
| CSV 数据 | 只认 `.xlsx/.xls`，`2025 ... .csv` 被静默丢弃 | 支持 CSV，自动识别 UTF-8 / GB18030 |
| 涨跌配色 | 红柱实际出现在「变容易」的年份，与说明页相反 | 统一为「红 = 更难」，个股纵轴翻转 |
| 聚合性能 | 4 处循环里反复遍历全部院校收集年份，O(n²) | 单次遍历建桶，再出结果 |
| 数据持久化 | 无，刷新即丢 | IndexedDB 自动缓存，可一键清空 |
| 导出 | 「导出全部」只是弹窗提示 | 真正导出，每校一个工作表 |
| 图表 | 三张图各自带滑块，缩放不同步；`markPoint` 用了无效的 `valueDim` | 单滑块 + 联动缩放；极值标记显式指定坐标 |
| 健壮性 | 列名不匹配就静默跳过，无任何提示 | 控制台列出每个被跳过文件的原因，界面汇总提示 |
| 可维护性 | 单文件 1368 行，HTML/CSS/JS 混在一起 | 10 个 ES 模块 + 3 个样式/页面文件 |
| 部署 | 仓库名 `-`，文件夹名带空格，无法启用 Pages | 规范工程结构，可直接开 GitHub Pages |

被删除的文件：`debug.html`（旧的调试页，逻辑已过时）、`浮动柱状图例子.txt`（移到 `docs/reference/` 备查）。
旧版本仍完整保留在 git 历史里，随时可以取回。

## 数据来源与免责声明

数据应来自各省教育考试院官方发布的录取统计表或高校官网。
本项目只是可视化工具，聚合口径（加权平均、百分位）是一种**近似**，不等同于官方录取难度排名，请勿作为志愿填报的唯一依据。
