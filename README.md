# 高考顺 gaokaoshun

> 把高考录取**位次**当作股票 **K 线**来分析：大盘、板块、个股三个维度，看一所学校、一个地区、一个层次的高校历年到底变难还是变容易。

位次（排名）不受试卷难度影响，跨年可比，所以它比分数更适合做趋势分析。
本项目用 ECharts 画出 K 线 + 成交量柱 + 分差柱，并聚合出区域指数与板块指数。

## 快速开始

数据只在你的浏览器里解析，不会上传到任何服务器。

### 方式一：在线访问

部署在 GitHub Pages 后直接打开项目主页，点右上角「📁 加载文件夹」选择数据目录。

### 方式二：本地一键启动（推荐，零依赖）

双击项目根目录的 **`启动.cmd`**。

它会调用 `tools/serve.ps1`（纯 PowerShell 写的静态服务器，不需要 Node / Python），
自动打开 <http://127.0.0.1:8137/>。

> 为什么不能直接双击 `index.html`？本项目用 ES Module 组织代码，
> 浏览器禁止在 `file://` 下加载模块。直接打开时页面会显示明确提示，而不是白屏。

### 方式三：已有 Node.js

```bash
node tools/serve.mjs        # 默认 http://127.0.0.1:8137/
npm start
```

## 数据怎么填

### 一张表就够了（推荐）

点顶部「**📄 模板**」下载 `高考顺_数据模板.xlsx`，在「分数数据」表里一行填一个专业：

| 年份 | 招生省份 | 院校名称 | 院校所在地 | 板块 | 专业名称 | 最高分 | 最低分 | 最高位次 | 最低位次 | 录取人数 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 2025 | 天津 | 天津工业大学 | 天津 | 双一流 | 计算机科学与技术 | 630 | 610 | 7000 | 11000 | 10 |
| 2024 | 天津 | 天津工业大学 | 天津 | 双一流 | 计算机科学与技术 | 620 | 600 | 8000 | 12000 | 10 |

必填只有四列：**年份 / 招生省份 / 院校名称 / 专业名称**，外加 **最低位次**。
其余列缺失时会自动兜底（最高位次 ← 最低位次，最高分 ← 最低分，区块 ← 双非，所在地 ← 文件夹名）。

一个文件可以放任意多行、任意多学校、任意多年份；文件名和目录层级都不再有约束。

### 考生数表（强烈建议）

位次要除以该省当年考生总数，才能跨省、跨年比较。可以放在同一个工作簿的第二个 sheet，也可以单独一个文件：

| 年份 | 省份 | 考生数 |
| --- | --- | --- |
| 2025 | 天津 | 74000 |
| 2024 | 天津 | 70800 |

缺少的年份按 7 万估算，界面会提示「估算」。

### 仍然兼容旧格式

```
年份 招生省份 院校名称 板块 考生数.xlsx
例：2025 天津 天津工业大学 doublefirst 74000.xlsx
```

支持 `.xlsx` / `.xls` / `.csv`；CSV 自动识别 UTF-8 与 GB18030（Excel 导出的中文 CSV 常是后者）；
表头不必在第一行，会向下扫描 15 行自动定位。

## 计算口径

```
专业平均位次 = (最高位次 + 最低位次) / 2
院校收盘位次 = Σ(专业平均位次 × 录取人数) / Σ(录取人数)      # 缺人数时等权
开盘位次     = 上一年收盘位次（首年 = 当年收盘）
上/下影线    = 当年所有专业里最好 / 最差的位次
百分位       = 院校收盘位次 / 该省当年考生数 × 100
热度指数     = 100 - Σ(各校百分位 × 招生人数) / Σ(招生人数)
```

**为什么先算百分位**：位次的绝对值跨省不可比 —— 天津第 10000 名和北京第 10000 名不是一回事，
两省考生规模也不同。旧版直接把原始位次加权平均再除以一个分母，量纲是错的。
现在先把每所学校换算成「在本省排前百分之几」，再按招生人数加权，不同省份的学校才能放进同一个指数。

**视觉约定**：个股纵轴翻转（第 1 名在最上方），指数纵轴正常；
两种模式都满足「向上 = 变难考」，红色统一表示「比上一年更难」。

### 三个附加指标

```
录取率估计 = 招生人数 ÷ 收盘位次 × 100        # 把扩招/缩招的影响从价格里除掉
相对强度   = 本校百分位 − 同省同板块平均百分位  # 单位 pp；负数=比同类更难
断档标记   = |同比变化 − 中位数| > max(3×1.4826×MAD, 20%)
```

- **录取率估计**：位次变化可能只是扩招造成的（招 10 人扩到 30 人，位次必然下滑，竞争却没变）。
  这个指标同时控制了供给和考生规模。
- **相对强度**：单看绝对走势分不清"它变难"还是"全省变难"。图上灰色虚线就是同类基准，
  顶部「相对同类」显示差值。
- **断档检测**：用 MAD 而不是均值±3σ——后者会被异常值本身拽走（掩蔽效应）。
  突然断档的年份会在图上打橙色「断档?」标记，提示你别拿它做趋势判断。

## 三张图

| 图 | 内容 | 说明 |
| --- | --- | --- |
| K 线 | 开盘 / 收盘 / 最高 / 最低位次 | 个股按位次，指数按热度；叠加同类基准虚线 |
| **成交量柱** | 当年招生总人数 | 红=扩招，绿=缩招，与 K 线联动缩放 |
| **分差柱** | 专业最低分的 P10–P90 | 浮动柱状图，比 max−min 更抗极值 |

两张柱状图是刻意保留的：量价配合（招生缩减但位次上升 = 疑似"饥饿营销"）和分差扩张，
是判断"真热门"还是"虚火"最直观的两个信号。

### 已知局限

- **文理分科省份**：位次是科类内排名，而「考生数」填的是全省总数，会系统性低估百分位约一半
  （天津、浙江这类综合改革省份不受影响）
- **专业改名断档**：以专业名为键，"计算机科学与技术(中外合作)"改成"计算机类"就会被当成两只股票
- **样本量小**：录取数据通常只有 5–7 年，任何趋势判断的统计功效都很低。这张图是用来**解释历史**的，
  不是用来**预测明年**的——所以本项目不提供任何"金叉/死叉"信号
- **开盘价是构造值**：`开盘 = 上一年收盘`，K 线实体本质是"两年收盘之差"，请不要按股票形态学解读

## 数据采集：掌上高考导出脚本

`tools/gaokao-exporter.user.js` 是一个 Tampermonkey 用户脚本，能把掌上高考的「院校分数线」导出成本项目能直接加载的 CSV。

### 为什么不做抖音

抖音是视频平台，分数线在那里不是结构化数据；而且抖音的接口签名（`a_bogus` 等）比掌上高考更难，风控也更严。
数据源头本来就是 `gaokao.cn`，绕道抖音只是多一层壳。

### 脚本怎么工作

1. 打开院校的「历年分数」页，页面自己会发一条带 `signsafe` 的请求
2. 从性能时间线里把这条**已经签好名**的 URL 捞出来
3. 实测该签名**不覆盖 `year` 参数**，于是原样重放、只替换年份 → 一次拿到 6 年数据
4. 逐校循环，结果存 `localStorage`，最后拼成模板 CSV

省份通过 `localStorage.localprovinceid` 切换，绕开了那个点不动的自定义下拉。

### 安装

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)
2. 扩展图标 → 添加新脚本 → 清空 → 粘贴 `tools/gaokao-exporter.user.js` 全文 → 保存
3. 打开任意 `https://www.gaokao.cn/school/<id>/special` 页面，右下角会出现面板
4. 选招生省份 → 刷新页面生效 → 点「批量抓取前 100」

约 20–30 分钟，期间别关标签页；中途可以暂停，进度存在浏览器里，能接着跑。

### 已知限制（不隐藏）

| 限制 | 说明 |
| --- | --- |
| **只有院校级数据** | 拿到的是「全校最低分/最低位次」，没有分专业、没有最高位次和分差 |
| **部分年份没有位次** | 2021–2022 很多省份官方不公布位次，这些年份会被跳过（CSV 里不出现） |
| **未登录只有前 5 个专业** | 页面固定 `size=5`，且签名覆盖该参数改不了；前 5 个专业是偏样本，所以脚本**不采用**专业级数据 |
| **批次已固定** | 同一年可能同时有本科批/提前批，脚本统一取「普通类 + 本科批」，避免序列在批次间跳变 |

要拿专业级全量数据，只能登录后再看请求是否放开——这一点我没法在无登录环境替你验证。

## 相比旧版的改动

旧版是一个 1368 行的单文件 `gaokaoshun.html`。

| 类别 | 旧版 | 现在 |
| --- | --- | --- |
| 数据填入 | 一个文件只能装一所学校一年，元数据写在文件名里，改格式极易出错 | 一张汇总表装下所有数据；附模板下载 |
| 指数算法 | 原始位次跨省加权平均，量纲不可比 | 先换算成省内百分位再加权 |
| 考生数 | 只取第一个文件的值当全局分母 | 按「省份 × 年份」维护，可单独一张表 |
| 均线周期 | 读取不存在的输入框 | 四个真实输入框，且周期超过样本量时自动不画 |
| CSV | 只认 xlsx/xls，2025 浙江数据被静默丢弃 | 支持 CSV，自动识别 UTF-8 / GB18030 |
| 涨跌配色 | 红柱实际出现在「变容易」的年份 | 统一「红 = 更难」 |
| 基准对比 | 只有绝对走势，分不清是本校变难还是全省变难 | 叠加同省同板块基准线 + 相对强度（pp） |
| 供给影响 | 扩招缩招被当成难度变化 | 新增录取率估计，把供给从价格里除掉 |
| 异常值 | 断档年份污染均线，无提示 | MAD 稳健检测，图上标「断档?」 |
| 分差口径 | max−min，专业越多极差越大 | 改用 P10–P90，更抗极值 |
| 聚合性能 | 4 处 O(n²) 重复扫描 | 单次遍历建桶 |
| 持久化 | 无，刷新即丢 | IndexedDB 自动缓存 |
| 导出 | 「导出全部」只是弹窗 | 真导出，每校一个工作表 |
| 结构 | 单文件 1368 行 | 10 个 ES 模块 + 独立说明页 |

## 数据来源与免责声明

数据应来自各省教育考试院官方发布的录取统计表或高校官网。
本项目只是可视化工具，聚合口径（百分位加权）是一种**近似**，不等同于官方录取难度排名，
请勿作为志愿填报的唯一依据。
