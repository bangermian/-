把录取位次当股票看

核心指标是位次而不是分数 —— 位次不受试卷难度影响，跨年可比。

1. 核心概念

系统把高考录取数据对标股票 K 线：一所院校（或一个专业）就是一只股票，每年的录取位次就是价格。

  • 个股：某所院校在某省招生的历年位次走势
  • 板块：同一地区 / 同一层次（92、双一流、S11 等）院校的整体表现
  • 大盘：某个大区（东部、中部等）的整体竞争激烈程度
位次越小越难考。所以个股图的纵轴是翻转的：第 1 名在最上方，"向上"= 变得更难考。

2. 数据文件格式

文件夹结构

按学校所在地分文件夹存放，系统会递归读取子文件夹，并支持多次加载不同省份的文件夹（数据自动合并）。

data/
├── 天津/
│   ├── 2024 天津 天津工业大学 doublefirst 70800.xlsx
│   └── 2025 天津 天津工业大学 doublefirst 74000.xlsx
└── 浙江/
    ├── 2024 天津 温州肯恩大学 s11 70800.xlsx
    └── 2025 天津 温州肯恩大学 s11 74000.csv

一级文件夹名即"学校所在地"，用于地区板块聚合。

文件名规范

年份 招生省份 院校名称 板块 考生数.xlsx
字段是否必填说明
年份必填4 位数字，如 2025
招生省份必填该院校在哪个省招生，如 天津
院校名称必填如 天津工业大学，允许包含空格
板块可选92 / doublefirst / newresearch / s11 / shuangfei；缺省按双非处理
考生数可选该招生省份当年考生总数，用于把位次换算成百分位

表格内容

列名是否必填说明
专业名称必填如 计算机科学与技术
最低位次必填该专业录取的最低位次（靠后）
最高位次建议填缺省时自动用最低位次填充
最高分 / 最低分建议填缺一补一；都缺则隐藏"分差图"
录取人数建议填缺省按 0 处理（聚合时权重退化为等权）

支持 .xlsx / .xls / .csv。CSV 会自动识别 UTF-8 与 GB18030 编码。表头不必在第一行，系统会向下扫描最多 12 行自动定位表头。

3. 计算公式

专业平均位次

(最高位次 + 最低位次) ÷ 2

院校收盘位次

Σ(专业平均位次 × 该专业录取人数) ÷ Σ(录取人数)

开盘位次

上一年的收盘位次；首年开盘 = 当年收盘。

上下影线

上影线取当年所有专业里最好的位次，下影线取最差的位次。

百分位与热度指数

百分位 = 加权平均位次 ÷ 该区域考生总数 × 100
热度指数 = 100 - 百分位

分母的算法：每个招生省份的考生数按「省份 × 年份」分别记录；大区则把成员省份的考生数相加。 旧版本只取第一个文件里的考生数当全局分母，跨省、跨年都会算错，这一版已修正。 分数缺失考生数时使用 70000 兜底，并在悬浮提示里标注"估算"。

热度指数越大 → 该区域/板块整体越难考。个股与指数的图形都满足"向上 = 变难"。

4. 怎么看 K 线

红 比上一年更难（位次下降 / 热度上升） 绿 比上一年更易（位次上升 / 热度下降）
  • 实体：开盘到收盘的区间，实体越长说明当年变化越大
  • 影线：当年最好 / 最差的位次
  • 成交量柱：当年招生总人数，红=扩招，绿=缩招
  • 均线 MA：近 N 年的收盘均值，判断长期趋势；周期可在左侧面板改
  • 图钉标记：标出历年最难（红）与历年最易（绿）的年份
  • 分差图：最高专业最低分与最低专业最低分的差值，反映校内专业冷热差距

5. 走势解读

  • 连续红柱 → 录取难度逐年上升，竞争加剧
  • 连续绿柱 → 难度下降，报考更容易
  • K 线在均线上方 → 当前难度高于长期平均
  • MA5 上穿 MA20（金叉） → 短期难度抬升，可能启动上升趋势
  • MA5 下穿 MA20（死叉） → 热度走弱
  • 量价背离：位次上升但招生人数大幅缩减 → 热度可能靠"饥饿营销"虚高，需警惕

6. 操作提示

  • 点「📁 加载文件夹」选数据根目录，系统递归读取全部 Excel/CSV
  • 切换「大盘 / 板块 / 个股」查看不同维度，三张图联动缩放
  • 个股页输入院校与招生省份 → 点「加载个股」；下拉可切到单个专业
  • 均线周期（MA1~MA4）改动后自动重绘，设置会记住
  • 「📤 导出当前个股」支持纵向专业格式 / 横向年份格式
  • 「📤 导出全部」把每所院校导成一个工作表
  • 数据与手录记录自动存到浏览器本地（IndexedDB），刷新不丢；点「🗑 清空」可清除

7. 常见问题

双击 index.html 打开是白屏 / 只在顶部提示？

本项目用 ES Module 组织代码，浏览器禁止在 file:// 下加载模块。请双击项目根目录的 启动.cmd，或访问 GitHub Pages 在线版。

加载后提示"文件名不规范"？

文件名必须至少包含「年份 招生省份 院校」三段，用空格分隔，例如 2025 天津 天津工业大学.xlsx。板块与考生数可省略。控制台（F12）会列出每一个被跳过的文件及原因。

图表区域一片空白，但数据列表有数据？

通常是图表库没加载成功。检查网络，或把 echarts.min.js、xlsx.full.min.js 放进项目根目录的 vendor/ 文件夹，页面会优先使用本地副本。

为什么"大盘/板块"不能手动录入？

因为大盘与板块是聚合结果，由个股数据自动算出。手动录入会和自动值互相覆盖，所以旧版那两个表单已被移除；要修正数据请到「个股」页手动录入。

同一个文件夹加载两次会重复吗？

不会。写入以「院校 + 专业 + 年份」为唯一键，重复加载是幂等的（覆盖更新）。
