📖 高考顺 · 完整使用说明

1. 核心概念与数据来源

本系统将高考录取数据对标股票K线分析，用 位次（排名） 作为核心指标，因为位次不受试卷难度影响，跨年可比。数据应来自各省教育考试院官方发布的《普通高校在津招生录取最低分统计表》或高校官网的录取分数统计。

2. 数据文件格式

📁 文件夹结构

  • 按 学校所在地 分文件夹存放，例如：天津/ 文件夹放天津工业大学等天津高校的Excel文件。
  • 系统会递归读取所有子文件夹中的 .xlsx 或 .xls 文件，且支持多次加载不同省份文件夹，数据会合并。

📄 文件名规范

年份 招生省份 院校名称 板块 考生数.xlsx
示例：2025 天津 天津工业大学 doublefirst 70800.xlsx
  • • 年份：4位数字，如 2025
  • • 招生省份：该院校在哪个省招生，如 天津
  • • 院校名称：如 天津工业大学（可含空格）
  • • 板块：92 / doublefirst / newresearch / s11 / shuangfei
  • • 考生数（可选）：该招生省份当年的总考生人数，用于大盘百分位数计算，如 70800

📊 Excel 内部列（必须包含）

专业名称, 最高分, 最低分, 最高位次, 最低位次, 录取人数
  • • 专业名称：如 计算机科学与技术
  • • 最高分 / 最低分：该专业录取的最高/最低分数（可留空，但建议填）
  • • 最高位次：该专业录取的最高位次（靠前，即该分数对应的累计人数）
  • • 最低位次：该专业录取的最低位次（靠后，即该分数对应的累计人数）
  • • 录取人数：该专业招生人数
⚠️ 如果缺少“最高分”或“最高位次”，系统会自动用“最低分”或“最低位次”填充。

3. 核心计算公式

📌 专业加权平均位次

每个专业的平均位次 = (最高位次 + 最低位次) ÷ 2（如果只有最低位次，则用最低位次）。

📌 院校加权平均位次（个股 Close）

全校加权平均位次 = Σ(专业平均位次 × 专业录取人数) ÷ Σ(专业录取人数)

📌 开盘位次（Open）

当年开盘位次 = 上一年收盘位次（第一年开盘位次 = 当年收盘位次）

📌 大盘指数（百分位数）

大区（如东部）加权平均位次 ÷ 该区域所有招生省份的考生总数 × 100
数值越小 → 该区域考生整体竞争越激烈（越难考）

📌 地区板块热度指数

热度指数 = 100 - 百分位数
数值越大 → 该地区高校整体越热门（越难考）
计算过程：先按学校所在地分组，将所有该地区高校在全国各省的录取位次按招生人数加权，得到加权平均位次，再除以参考总人数得到百分位数，最后取反转为热度指数。

4. 如何看懂 K 线

红柱 表示 热度上升（位次下降 / 指数上升） 绿柱 表示 热度下降（位次上升 / 指数下降）
  • 实体：从开盘到收盘的区间，实体越长说明当年变化越大。
  • 上影线：当年最高点（最高位次 / 最高指数）。
  • 下影线：当年最低点（最低位次 / 最低指数）。
  • 成交量柱：当年招生总人数，柱色与K线颜色一致，便于量价配合分析。
  • 移动均线（MA）：MA5/10/20/30 分别为近5/10/20/30年的收盘加权平均位次，用于判断长期趋势。
  • 标记点：红点标注历史最高位次（最难年份），绿点标注历史最低位次（最容易年份）。

5. 不同走势的含义

  • 连续红柱 → 录取难度逐年上升，热度持续增加，报考竞争加剧。
  • 连续绿柱 → 录取难度逐年下降，热度减退，报考更容易。
  • K线在均线上方 → 当前热度高于长期平均水平。
  • K线在均线下方 → 当前热度低于长期平均水平。
  • MA5上穿MA20（金叉） → 短期热度开始超过中长期均值，可能启动上升趋势。
  • MA5下穿MA20（死叉） → 短期热度走弱，可能继续降温。
  • 量价背离：分数上涨但招生人数大幅缩减 → 热度可能靠“饥饿营销”虚高，需警惕泡沫。

6. 各指数用途

  • 大盘（东部/中部等）：反映该区域考生整体竞争激烈程度。数值越小说明该区域考生越难考。
  • 地区板块（天津/浙江等）：反映该地区高校整体热门程度。数值越大说明该地区高校越受欢迎。
  • 院校板块（92/S11等）：反映该类型高校的整体热度趋势，便于比较不同层次院校的报考热度。
  • 个股：查看具体院校的历年录取位次走势，可用于分析该校的报考难度变化。

7. 操作提示

  • 点击 “📁 加载文件夹” 选择存放所有Excel的根目录，系统自动读取全部文件。
  • 切换 大盘 / 板块 / 个股 标签查看不同维度的K线图。
  • 在 “个股” 页面输入院校名称和招生省份，点击“加载/新建个股”可查看该校数据。
  • 在 “板块” 页面可以选择“学校所在地”查看地区热度，或选择“区域+院校板块”查看组合指数。
  • 均线周期（MA1~MA4）可在左侧面板自定义调整，点击“更新均线”生效。
  • 点击 “📤 导出当前个股数据” 可将当前院校数据导出为Excel（纵向专业格式或横向年份格式）。
  • 点击 “📤 导出全部” 可批量导出所有院校数据（逐个院校导出）。

8. 数据补充与修正

  • 如果官方数据缺失“最高分”或“最高位次”，系统会用“最低分”/“最低位次”自动填充，K线上影线将缺失，但收盘价仍准确。
  • 手动录入数据时，请确保录入“年份”、“最高位次”、“最低位次”和“录取人数”，分数可为空。
  • 大盘百分位数依赖于“考生数”字段，请确保文件名中包含或手动设置。
